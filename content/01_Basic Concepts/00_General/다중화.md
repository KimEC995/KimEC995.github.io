# 다중화
> Multiplexing

다중화는 [[네트워크 다중화]]에 비해 좀 더 포괄적인 기술용어로 다양한 분야에서 사용한다. 주로 통신 기술 전반에 적용되는 포괄적인 개념으로, 통신 / 데이터 전송 / [[네트워크|네트워크]]와 같이 다양한 분야에서 사용한다.

다중화의 세부적인 내용에 따라 달라지겠지만, 기본적으로 다중화는 **하나의 물리적인 연결을 여러 논리적인 연결로 나누어** 통신의 효율이 높이는 기술을 말한다.

이 페이지에서는 네트워크 외의 포괄적인 개념의 다중화의 개념을 이야기하고, 네트워크의 세부 다중화는 [[네트워크 다중화]]에서 다룬다.
