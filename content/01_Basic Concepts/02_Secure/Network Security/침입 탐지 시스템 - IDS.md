네트워크 공격에 대해 방어를 할 때 일반적으로 3가지 방법을 사용한다.

- [[침입 방지 시스템 - IPS|IPS]]: 침입 방지 시스템

셋 다 보안을 지키는 녀석들로 비슷한 일을 하지만 기능과 쓰임새는 다르다.
이 셋의 차이는 [[IDS vs IPS vs Firewall]]을 보도록.

# IDS
> Intrusion Detection System

![[IDS(1).png]]

**IDS**는 수동적인 시스템으로 트래픽을 모니터링 / 스캔 후 위협을 감지하면 보고만 하는 침입 감지 시스템.
최근에는 IDS와 [[침입 방지 시스템 - IPS|IPS]]를 함께 사용하는 하이브리드형이 많고 차세대 방화벽에 이 둘의 기능이 통합되는 경우도 많다.

## IDS의 동작 흐름
동작 흐름 전체는 [[침입 방지 시스템 - IPS|IPS]]와 유사하지만, 대응에 따라 차이가 난다.

#### 1. 트래픽 수집(복제)
> Traffic Mirroring

**IDS**는 네트워크 경로에 직접 끼어드는게 아닌, [[00_Switch|스위치]]의 미러링 포트 또는 TAP 장비를 통해 트래픽을 **복제해서 수집**한다. 이로 인해 실제 [[패킷|패킷]]의 흐름에는 영향을 주지 않는다.

#### 2. 패킷 분석
> Packet Insepection

수집된 패킷의 헤더 수준을 분석한다. 이 때 [[프로토콜]] 위반, 포트 사용 이상, 패킷 길이, 특정 문자열 등을 검사한다.

#### 3. 공격 탐지
> Intrusion Detection

분석 후 여러 방식으로 공격 여부를 판단한다. 크게 시그니쳐 / 행위 / 정책을 기반으로 공격 여부를 판단한다.

**시그니쳐 기반**은 사전에 정의된 시그니쳐를 참조해 공격 여부를 확인하는 방식이다. 보통 IPS 업체는 다양한 공격 패턴들을 DB로 관리해 리스트화한다. 이름, 심각성 등등 정의되어 있다.

**행위 기반**은 정상적인 행동을 벗어난, 이상 행위를 탐지하는 방식으로 이상(Anomaly) 기반 방식이라고도 한다. 대표적으로 [[DoS, DDoS 공격]] 이 있다.

**정책 기반**은 네트워크 보안 정책 위반 여부를 확인한다.

#### 4. 알림 및 로그 기록
공격으로 탐지되면 관리자에게 알림, 로그 기록 등을 수행한다. 직접적으로 차단하지는 않는다.
