네트워크 공격에 대해 방어를 할 때 일반적으로 3가지 방법을 사용한다.

- IPS: 침입 방지 시스템
- [[침입 탐지 시스템 - IDS|IDS]]: 침입 탐지 시스템
- [[방화벽 - Firewall|Firewall]]: 방화벽(침입 차단 시스템)

셋 다 보안을 지키는 녀석들로 비슷한 일을 하지만 기능과 쓰임새는 다르다.
이 셋의 차이는 [[IDS vs IPS vs Firewall]]을 보도록.

# 침입 방지 시스템
> Intrusion Prevention System

![[IPS(1).png]]

네트워크 보안 기술. **외부나 내부의 공격을 탐지 / 실시간 차단**하는 솔루션. [[침입 탐지 시스템 - IDS|IDS]] 처럼 트래픽을 분석하는데 더해 위협이 감지되는 즉시 자동으로 차단한다. 매우 **능동적인 대응**으로 차단 방식은 의심 트래픽 차단 / 세션 종료 등이 있다. 물론 능동적인 대응으로 인해 [[침입 탐지 시스템 - IDS|IDS]]에 비해 자원을 많이 소모한다.

최근에는 IDS와 [[침입 방지 시스템 - IPS|IPS]]를 함께 사용하는 하이브리드형이 많고 차세대 방화벽에 이 둘의 기능이 통합되는 경우도 많다.

## IPS의 동작 흐름
동작 흐름 전체는 [[침입 탐지 시스템 - IDS|IDS]]와 유사하지만, 대응에 따라 차이가 난다.
#### 1. 트래픽 수집
> Traffic Capture

IPS는 인라인 배치일 경우 [[00_라우터 - Router|라우터]]와 [[00_Switch|스위치]]의 중간에 위치해 **자신을 지나는 모든 [[Packet|패킷]]을 실시간으로 가져와서 분석한다.** 모든 패킷을 분석하기 때문에 성능 문제가 발생한다.

패시브 모드일 경우 [[침입 탐지 시스템 - IDS|IDS]]처럼 탐지만 수행하고, 실시간 차단은 별도 장비와 연동해야 하지만 트래픽에 영향을 주지 않아 성능 문제를 줄일 수 있다.

#### 2. 패킷 분석
> Packet Inspection

수집된 패킷의 헤더 수준을 분석한다. 이 때 [[00_프로토콜 - Protocol|프로토콜]] 위반, 포트 사용 이상, 패킷 길이, 특정 문자열 등을 검사한다.

#### 3. 공격 탐지
> Intrusion Detection

분석 후 여러 방식으로 공격 여부를 판단한다. 크게 시그니쳐 / 행위 / 정책을 기반으로 공격 여부를 판단한다.

**시그니쳐 기반**은 사전에 정의된 시그니쳐를 참조해 공격 여부를 확인하는 방식이다. 보통 IPS 업체는 다양한 공격 패턴들을 DB로 관리해 리스트화한다. 이름, 심각성 등등 정의되어 있다.

**행위 기반**은 정상적인 행동을 벗어난, 이상 행위를 탐지하는 방식으로 이상(Anomaly) 기반 방식이라고도 한다. 대표적으로 [[DoS, DDoS 공격]] 이 있다.

**정책 기반**은 네트워크 보안 정책 위반 여부를 확인한다.

#### 4. 위협 평가 및 정책 적용
공격으로 탐지되었다면, 이 공격의 위협에 대해 심각도 분류를 수행하고, 미리 설정된 정책에 따라 대응 여부를 결정한다.

예를 들어 고위험 공격은 즉시 차단, 중간 위험 공격은 관리자에게 알림, 저위험 공격은 로그 기록 정도.

#### 5. 정책 수행
정책이 적용되면 그 정책의 조치를 수행한다.

- 패킷 드롭
- 연결 종료
- 방화벽 연동 차단
- 관리자 알림

#### 6. 로그 및 리포트 생성
모든 탐지 / 차단 / 허용의 결과는 이벤트 로그로 기록되며 관련 자료는 중앙 관리 시스템으로 전송될 수 있다. 보통 추후 분석을 위한 리포트 또는 경고 알림으로 활용된다.

## IPS의 분류
IPS는 호스트 기반의 HIPS와 네트워크 기반의 NIPS로 나뉘는데 현재 대부분의 상용 IPS는 NIPS이다.

#### NIPS
> Network Intrusion Prevention System

![[IPS(1).png]]

**NIPS**는 [[00 What is Network|네트워크]]의 논리적 혹은 물리적 경계에 인라인 방식으로 설치한다. 이를 통해 모든 트래픽 수집 / 분석이 가능하며 공격 시도와 유해 트래픽을 감지해 차단하는 기능을 수행한다.

#### HIPS
> Host Intrusion Prevention System

![[IPS(2).png]]

**HIPS**는 각 호스트에 설치된 IPS 모듈이 시스템의 오남용 / 해킹 시도 / 이상 징후를 탐지하고 차단하는 기능을 수행한다. 시스템 레벨에서의 탐지 / 차단이라 신뢰성은 높지만 각 호스트별로 별도의 관리를 해줘야 해서 대규모 네트워크에서는 운영과 편의성이 떨어진다.
