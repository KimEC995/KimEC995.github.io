# 암호화
> Encryption

우선 암호화의 사전적 정의를 찾아보자.

```
암호-화 暗號化
명사

통신할 내용을 일정한 체계에 따라 암호로 바꿈.
```

```
암호 暗號
명사

정보·통신 - 특정한 시스템에 로그인을 할 때에 사용자의 신원을 확인하기 위하여 입력하는 문자열.
```

즉 **[[평문]]을 일정한 체계에 맞춰 누구나 알아볼 수 없는 문자로 만든 것을 암호라고 하고, 이 과정을 암호화 라고 한다.**

암호화는 다양한 방법을 이용해 평문을 암호로 만드는데, 이 방법들을 [[암호 알고리즘의 분류|암호 알고리즘]] 혹은 암호 시스템이라고 한다.

# 복호화
> Decryption

사전적 정의는

```
복호^과정 復號過程

정보·통신 - 암호문을 평문으로 변환하는 방법을 아는 상태에서 평문을 얻는 과정
```

**[[암호화와 복호화|암호화]]에서 사용된 [[암호 알고리즘의 분류|암호 알고리즘]]을 알고, 이를 이용해 다시 [[평문]]으로 만드는 과정을 복호화라고 부른다.**

가장 중요한 점은 **암호 -> 평문의 알고리즘을 아는 상태**여야 복호화라고 할 수 있다. 
모르는 상태에서 [[리버싱 엔지니어링]] 혹은 크래킹을 이용해 [[암호키]]를 얻어냈다면 이는 복호화가 아닌 **암호 해독** 과정이다. 복호화와 암호 해독은 엄연히 다른 개념이다.

복호화 혹은 역암호화 라고도 한다.
