# 대칭키 알고리즘
> Symmetric Key Algorithm

**대칭 키 알고리즘**은 [[암호 알고리즘의 분류#양방향 알고리즘|양방향 암호 알고리즘]]의 한 종류로, **하나의 [[암호키]]를 이용해 [[암호화와 복호화]]를 수행하는 알고리즘**을 말한다.

대칭 키 알고리즘은 암호화하는 측과 복호화 하는 측이 동일한 암호키를 공유해야 한다. 동일한 키를 사용하기 때문에 **연산 속도가 빠르고 단순하다는 장점**이 있다. 이로 인해 [[네트워크]]의 데이터를 암호화하는 [[TLS]]와 [[SSL]]에서 많이 사용했지만, 최근에는 [[복합 암호 알고리즘]]을 더 활용하는 편이다.

단, 하나의 키를 이용해 암/복호화가 가능하기 때문에 **키 교환 / 분배 문제**가 발생한다. 이 문제를 해결하기 위해 최근에는 [[복합 암호 알고리즘]]을 주로 사용한다.

---
## 대칭키 알고리즘의 키 교환 문제
대칭 키 알고리즘은 하나의 [[암호키]]를 이용하기 때문에 데이터의 송 / 수신자는 동일한 암호키를 지녀야 한다. 그래서 송신측이 [[평문]]을 [[암호화와 복호화|암호화]]한 후 그 데이터를 수신측에 전송할 때 복호화할 수 있는, 동일한 암호키를 함께 보내게 된다. 

여기서 문제가 발생하는데, 만약 공격자가 [[세션 하이재킹|세선을 갈취할 경우]] 공격자는 데이터를 복호화할 수 있는 키까지 얻을 수 있다. 이렇게 되면 공격에 대한 취약점이 생기고, 이를 키 교환 문제라고 한다. 키 분배 문제라고도 한다.

1. **송신자는 전달할 평문 데이터를 암호화 한다.**

![[대칭키 알고리즘(1).png]]

2. **송신자는 준비된 암호를 수신자에게 전달한다. 이 때 수신자는 복호해야 하니 암호키도 함께 보낸다.**

![[대칭키 알고리즘(2).png]]

3. **공격자에 의해 갈취당한다.**

![[대칭키 알고리즘(3).png]]

4. **복호를 위한 키도 함께 얻었다. 공격자는 편하게 복호한다.**

![[대칭키 알고리즘(4).png|328x214]]

이런 문제를 해결하기 위해 [[공개키 알고리즘]], [[복합 암호 알고리즘]]을 사용해 방어한다.
