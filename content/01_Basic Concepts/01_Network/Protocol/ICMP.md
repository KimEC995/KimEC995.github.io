# ICMP
> Internet Control Message Protocol -> 인터넷 제어 메시지 프로토콜

- **프로토콜**: [[IP - Internet Protocol|IP]]
- **프로토콜 번호**: [[IPv4 헤더#프로토콜(8Bit)|0001]]
- **계층**: [[OSI 7 Layer & TCP,IP 4 Layer#네트워크 계층|네트워크 계층(L3)]]
- **역할**:  네트워크 상태 보고 / 오류 메시지 관련

**ICMP**는 [[라우터]]에서 **통신 문제를 진단하는데 사용**하는 프로토콜이다. 주로 데이터가 의도한 수신자에게 잘 도달했는지의 여부를 확인한다. 가끔 [[DoS, DDoS 공격|DoS공격]]에 사용되기도 한다. [[OSI 7 Layer & TCP,IP 4 Layer|전송 계층(L4)]]에 접근하는 데이터가 아니고 `L3`계층에서만 동작하는 **제어/진단용 프로토콜**이다. 따라서 `L4`에서 오류가 발생하면 ICMP는 이에 관여하지 않는다.

주요 목적은 **오류 보고**이다. 목적지에 도달하기 전에 [[TTL]]이 0이 되어서 폐기할 때, 도달 불가능한 주소일 때, 목적지의 포트가 닫혔을 때 등 다양한 오류가 발생하면 그에 맞는 타입을 설정한 뒤 송신자에게 메시지를 송신한다.

보조 목적은 **네트워크 진단을 수행**하는 것이다. 일반적으로 [[ping]]이나 [[Ptracert]]는 ICMP를 사용해 동작한다. 이는 네트워크의 경로나 상태를 확인해 네트워크 지연 원인을 파악할 때 유용히 사용한다.

오류 보고 혹은 네트워크 진단을 요청/수행한 경우 [[패킷]]의 데이터는 일반적인 네트워킹의 구조가 아니라 ICMP의 헤더와 [[페이로드]]를 포함한다.

```
제어/진단시: [IP 헤더] + [ICMP 메시지(헤더 + 페이로드)]
```
