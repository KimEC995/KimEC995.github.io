# 네트워크
> Network

단어부터 뜯어보면

```
Net + Work -> 망 + 일 -> 망으로 연결되는 일
```

**무엇을 연결하는 수단을 의미**한다.
즉 두 대 이상의 준비된 PC가 서로 연결해서 데이터를 주고 받기 위한 수단.

네트워크가 세상에 나타나면서 엄청난 장점을 가져왔다. 우선 PC와 기타 디바이스들을 연결하기 쉬워졌다. 과거엔 모두 [[통신 매체의 분류|물리적 통신 매체]]를 이용해야 했기 때문에 단가, 유지보수 등 여러가지 고려 사항이 있었지만, 네트워크의 등장으로 해당 네트워크 토플리지에 참여만 하면 물리적인 경계를 넘을 수 있는 통신이 가능해졌다. 이로 인해 정말 **다양한 정보를 손쉽게 공유**할 수 있게 되면서 인간의 기술 발전 속도도 함께 폭발적으로 증가했다.

하지만 그와 동시에 네트워크로 인한 단점도 많다. 우선 해킹과 악성코드의 확산으로 경제적, 심리적 악영향을 끼치고 **데이터의 무결성을 침해**해 올바른 정보를 얻는데에 많은 고려가 필요하게 되었다. 이에 대비하기 위해 정말 많은 [[정보보안]]의 방법론과 수단이 생겨났지만, 보안이 확산되는 속도보다 악성 코드의 확산 속도가 더 빨라 여전히 여러 분야에 피해를 끼치고 있다.

## 네트워크 설계시 고려 요소
#### 네트워크 가용성
> Network Availability

시스템이나 서비스가 중단 없이 동작할 수 있도록 설계하는 것.
[[네트워크 고가용성 - HA#링크 이중화 / 이중 경로|이중화]], [[네트워크 고가용성 - HA#로드 벨런싱|로드 벨런싱]], 장애 복구 계획 등으로 가용성을 구성한다. [[IP - Internet Protocol#비신뢰성|IP의 비신뢰적 특징]]도 이를 위한 결과이다.
#### 네트워크 확장성
> Network Scalability

네트워크가 성장할 때 쉽게 확장할 수 있는 설계를 고려한다. 사용자 수의 급증, 데이터 사용 급증 등의 상황에서 성능 저하 없이 추가적인 리소스를 반영할 수 있다.

[[네트워크 다중화]] 등 유연한 대응의 기본 원리가 된다.

#### 네트워크 보안
> Network Security -> [[정보보안#네트워크 보안|네트워크 보안]]

네트워크는 외부 공격이나 내부 위협으로부터 보호되어야 한다.

#### 네트워크 신뢰성
> Network Reliability

네트워크의 고장이 발생할 때 최대한 빠르고 정확하게 복구될 수 있도록 설계되어야 한다.

## 구성 범위(거리)에 따른 네트워크의 분류
네트워크의 거리에 따라 분류가 나뉜다. 익히 들어본 [[LAN - 근거리 통신망|LAN]]도 여기에 포함됨.
블로그에는 주로 [[LAN - 근거리 통신망|LAN]]과 [[WAN - 광역 통신망|WAN]]위주로 작성할 것 같다.

LAN과 WAN의 구분은 다양하지만 **내부 / 외부 네트워크와의 연결**을 중점적으로 본다.

#### PAN
> Personal Area Network

5M 이내의 **가까운 거리와 연결**이 가능.
주로 웨어러블 기기 등이 여기에 포함됨.

#### LAN
> Local Area Network -> [[LAN - 근거리 통신망|LAN]]

하나의 [[Router|라우터]]아래의 범위(근거리)를 LAN으로 본다. 물론 `라우터 + 라우터`의 연결도 사설 [[IP - Internet Protocol|IP]]를 사용하거나 동일 네트워크에 묶인다면 이 또한 LAN이라고 부른다.

즉 **LAN은 한정된 범위의 네트워크를 의미한다.**

그렇게 LAN이 모여 MAN이 되고, [[WAN - 광역 통신망|WAN]]이 되고...

하나의 라우터 아래이기 때문에 보통 한 건물 등 근거리(KM) 위주로 통신을 담당하며 연결이 편리하다.

#### MAN
> Metropolitan Area Network

[[LAN - 근거리 통신망|LAN]]과 [[WAN - 광역 통신망|WAN]]의 사이 범위.

#### WAN
> Wide Area Network -> [[WAN - 광역 통신망|WAN]]

[[LAN - 근거리 통신망|LAN]]의 집합/연결체 혹은 [[Router|라우터]] 바깥 범위를 [[WAN - 광역 통신망|WAN]]이라고 한다. 물론 라우터가 공인 [[IP - Internet Protocol|IP]]에 접근한다면 말이지.

[[LAN - 근거리 통신망|LAN]]과 반대로 **[[WAN - 광역 통신망|WAN]]은 외부 네트워크와의 연결을 의미**한다.

## 네트워크의 데이터 교환 방식
> Network Data Switching Methods -> [[네트워크의 데이터 교환 방식]]

네트워크의 통신 방식 중 하나로 가장 보편적으로 사용하는 방식이다.
[[패킷]]교환 방식, 데이터 교환 방식, 회선 방식 등 많은 이름으로 불리고 있으나 통일과 이해를 위해 이제부턴 **네트워크의 데이터 교환 방식**이라는 포괄적인 이름으로 부를 예정이다.

네트워크의 한 지점에서 다른 지점으로 데이터를 전송하는 **[[통신 매체의 분류|물리]] 및 무선 경로를 말한다.** 이 회선은 [[LAN - 근거리 통신망|LAN]], [[WAN - 광역 통신망|WAN]]에서 모두 사용하며 장치를 연결하는 기본이 된다.

자세한 내용은 [[네트워크의 데이터 교환 방식]] 참고.
