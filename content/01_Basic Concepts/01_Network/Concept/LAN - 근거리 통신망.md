# LAN
> Local Area Network -> 근거리 [[00_ What is Network|네트워크]]

범위적인 의미로는 하나의 네트워크 내부 / 혹은 동일 네트워크의 내부를 의미한다. 즉 **사설 / 내부 네트워크**. 일반적으로 [[Router|라우터]]아래의 범위를 하나의 LAN으로 보는 시각이 많지만, 만약 `라우터 + 라우터`의 결과가 동일한 사설 네트워크를 구축한다면 이는 LAN이다.
