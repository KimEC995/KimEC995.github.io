# SSL
> Secure Socket Layer

- **프로토콜**: [[TCP]]
- **포트 번호**
	- HTTPS -> 443
	- SMTPS -> 465
	- IMAPS -> 993
- **계층**: [[OSI 7 Layer & TCP,IP 4 Layer|OSI 7계층]]의 L4에서 L7까지 **유기적으로 동작**함
- **역할**
	- L7에서의 **보안 통신([[암호화와 복호화|암호화]])** 을 제공함
	- 단, 더이상 직접적으로 사용하진 않음 후속 표준인 [[TLS 프로토콜|TLS]] 사용 권고
- **관련 공격**
	- [[Heartbleed]] 취약점

웹 브라우저와 웹 서버간의 안전한 데이터 전송을 위한 [[프로토콜]]을 목적으로 `netscape`사에서 개발되었다. [[정보보안]] 측면에서 아주 중요한 프로토콜인데, 회사에서 만든 프로토콜을 국제 표준으로 지정하긴 좀 뭐시기 해서 [[TLS 프로토콜|TLS]]를 개발, SSL은 96년 이후 업데이트되지 않고있다. 근데 [[TLS 프로토콜|TLS]]를 사용해도 TLS라 안부르고 SSL이라고 부르는 추세라서 사용시 정확히 확인할 필요가 있다. **2015년부터 SSL 3.0은 공식적으로 사용 중단 권고 상태이다.**

오픈소스 구현판으로 [[Openssl]]이 있었지만, 현재 Openssl은 TLS로 대체되었다.
