# 네트워크 다중화
> Network Multiplexing

[[다중화]]의 세부적인 개념으로, [[네트워크]] 환경에서 **하나의 물리적 네트워크 링크를 여러 개의 논리적인 네트워크 경로로 나누어 데이터를 전송**하는 기술. 네트워크 환경에서의 다양한 네트워크 트래픽을 효과적으로 분배하고 최적화하는 방향으로 초점을 뒀다. 이에 효율적인 데이터 전송 / 대역폭 관리를 실현하는 기술을 중점적으로 다룬다.
