# 페이로드
> Payload

전송되는 **순수한 데이터**를 의미한다.

즉, 보통 데이터가 전송되면 

```
[프로토콜의 헤더: 메타데이터] + [그 외 데이터: 페이로드]
```

의 형식으로 전송되는데, [[메타데이터]]를 제외한 순수한 데이터를 말한다.

하지만 [[캡슐화 - Encapsulation|캡슐화]]의 개념으로 인해 보통 페이로드 내부에는 상위 계층의 메타데이터가 또 들어있다.
