# 네트워크 식별자
> Network Identifier

[[네트워크]] 식별자는 **네트워크에 연결된 모든 물리적, 논리적인 개념들이 서로 통신할 때 서로를 구분할 수 있는 특별한 주소 체계를 말한다.** 이 식별자를 지녀야 통신이 가능하며, 이를 이용해 송/수신자를 특정한다.
